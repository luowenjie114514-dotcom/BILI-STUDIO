# 🐋 蓝色大肥鱼 · 自动化搬史

本机运行的 B 站「找视频 → 写评论 → @人 → 发布」任务台。带图形控制台，能手动按一下就跑，也能挂成定时任务自己跑。

当前版本 **v1.5.4** —— 变更历史见 [CHANGELOG.md](CHANGELOG.md)（界面右上角「更新日志」按钮也能直接看）。

**零 npm 依赖**，Node 18+ 就能跑；一条 `node build.mjs` 打成单文件 Windows exe。
[MIT 许可](LICENSE)，欢迎 fork —— 但请先读 [第五章「安全与风控」](#五安全与风控请认真看)。

## 一、启动

有两种跑法，**用哪种都行，别同时开**（会抢同一个端口）。

### 方式 A：独立 exe（推荐，不需要装 Node）

直接双击：

```
dist\bili-studio.exe
```

**双击后不会有黑窗口，浏览器会自动打开控制台页面**，直接就能操作。

自带 Node 运行时，拷到任何 Windows 机器都能跑。数据存在 **exe 同级的 `data\` 目录**。

命令行参数（从终端启动时，输出照常显示在终端里）：

```powershell
.\dist\bili-studio.exe --port=8899     # 换端口（也支持 --port 8899）
.\dist\bili-studio.exe --no-open       # 不要自动开浏览器
.\dist\bili-studio.exe --open          # 强制自动开（源码模式想自动开时用）
.\dist\bili-studio.exe --version       # 看版本
.\dist\bili-studio.exe --help          # 看全部选项
```

**关掉控制台**：点网页顶栏的 **⏻ 关闭控制台** 按钮即可（会二次确认）。
也可以用任务管理器结束 `bili-studio.exe` 进程。

> 数据目录想换地方（比如放 D 盘），设环境变量 `DSH_BILI_STUDIO_DATA` 指向目标文件夹。
>
> ⚠️ 别把 exe 放在 `C:\Program Files\` 这类需要管理员权限的目录，它要在同级写 `data\`。

> 💡 **不小心双击了两次？** 不会出问题：第二个实例发现端口被占用，会把已经开着的控制台页面再打开一次，然后自己退出，不会影响正在跑的那个。

### 方式 B：源码跑（开发/改代码用）

```powershell
cd <你 clone 下来的目录>
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

或者双击 `启动控制台.bat`。源码模式默认**不**自动开浏览器（`start.ps1` 会开），需要的话加 `--open`。

| 命令 | 作用 |
|---|---|
| `.\start.ps1` | 启动（已在跑就只提示，不重复起） |
| `.\start.ps1 -Restart` | 强制重启（改完代码用这个） |
| `.\start.ps1 -Port 8899` | 换端口 |
| `.\start.ps1 -NoBrowser` | 不自动开浏览器 |

### 重新打包 exe

```powershell
node build.mjs
```

一条命令完成：内嵌静态资源 → 合成单文件 bundle → 生成 SEA blob → 复制 node.exe → 注入 blob → **把 PE 子系统改成 GUI**。
**零 npm 依赖**（postject 的 wasm 内嵌在它的 `api.js` 里，不需要装原生工具）。
产物在 `dist\bili-studio.exe`（约 89 MB）。

> 注入会破坏 exe 的 Authenticode 签名，构建时会打印 `warning: The signature seems corrupted!`。
> **这是预期的，不影响运行**，只是文件属性里显示"未签名"。

启动后浏览器打开 **http://127.0.0.1:8787**（只监听本机，外网访问不到）。

停止服务：

```powershell
Get-NetTCPConnection -LocalPort 8787 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

## 二、控制台怎么用

界面从上到下 9 个区，正常流程是 **1 → 2 → 3 → 4 → 5 → 按执行**。

### 1. 账户（cookie）
粘 **`document.cookie` 整串**，或者把 **F12 → Network → 请求头原文整段**直接粘进来都行。程序会做关键词精准定位，自动挑出 `SESSDATA` / `bili_jct` / `buvid3` / `DedeUserID` 等字段，并立刻调一次接口测活，显示昵称和等级。

能认的形态：

```
SESSDATA=xxx; bili_jct=xxx          ← 纯 cookie
Cookie: SESSDATA=xxx; bili_jct=xxx  ← 请求头格式（名: 值）
SESSDATA="xxx"                      ← 带引号
SESSDATA=xxx                        ← 跨行
bili_jct=xxx
```

- 大小写不敏感、字段前后多余空格无所谓、`名: 值` 与 `名=值` 混排也能认。
- 共识别 12 个字段：`SESSDATA` `bili_jct` `buvid3` `buvid4` `buvid_fp` `DedeUserID` `DedeUserID__ckMd5` `b_nut` `_uuid` `bili_ticket` `sid` `rpdid`。
- 添加成功后会提示"识别到字段：…"，一眼看出有没有抠错。
- **`SESSDATA` 里的 `%2C` 等百分号编码会原样保留**（解码后回传 B 站会校验失败，这是个坑）。

> 支持多个账户，点「用它」切换当前使用的号。
> 注意：**Lv0 未转正的号发不了评论**（B 站返回 `-107`），先去答题。

### 2. @ 名单
填昵称，程序自动搜 mid（优先取完全匹配），也可以在搜索结果里点「加」。勾选框决定这个人参不参与本次 @。

### 3. 内容偏好
用大白话写你想搬什么史，比如"无厘头搞笑、抽象、年轻人下饭视频"。
点 **🧠 用 DS 分析并试搜**：DeepSeek 把它翻译成 3~5 个 B 站搜索关键词，并立刻试搜给你看命中效果。**分析结果会缓存**，之后每次执行直接用缓存，不会再重复消耗 token。

### 4. 问候语风格 & 署名
风格同样是自然语言，比如"暖一点，像小鲸鱼撒娇，简短自然"。生成评论时会把风格塞进 prompt。
署名会自动加破折号，最终评论长这样：

```
@Yaprussia @道馆恶魔三鹰朝 这条笑死我了 ——笨蛋鲸鱼娘
```

### 5. 任务参数
| 参数 | 说明 |
|---|---|
| 视频来源 | 按偏好搜索 / 手动指定 BV 号 |
| 每次跑几条 | 一轮处理几个视频 |
| 每条间隔 | 两条评论之间等多久（默认 12 秒，防刷屏） |
| 搜索翻几页 | 每关键词翻几页，越多候选越杂 |
| 每日上限 | 当天发满就自动停 |
| **干跑模式** | **默认开启：只预览不发送**。确认没问题再关掉 |
| **私信模式** | 勾上就改发**私信**，完全不碰评论区。右边的 **⚙** 可以选私信形态（见下） |

#### 私信模式

勾上「私信模式」之后，任务不再去视频下面发评论，而是**按 @ 名单一个人一个人发私信**。

- 内容由 **DS 写的私信正文 + 署名** 组成，**不会拼 @**（私信本来就是发给具体某个人的）。
  正文是「我今天刷到了什么」的**转述**：这条视频是干什么的、哪个点值得说、值不值得看——
  不是对着标题表演情绪（v1.5.1 改的，见 CHANGELOG）。
- **私信不读「问候语风格」**，那个框只管评论区的口吻；私信有自己一套写法和字数上限。
- 条数取「每次跑几条」，从 @ 名单里按顺序取前 N 个人；中间照样隔「每条间隔」秒。
- @ 名单里那个人如果还没查过 mid，会被跳过并提示先去「@ 名单」点「查 mid」。

勾选框右边有个小齿轮 **⚙**，点一下弹出悬浮面板（**点页面别处 / 再点一次齿轮 / 按 Esc** 都会收起），里面选形态：

| 形态 | 效果 |
|---|---|
| **原生卡片** | 把视频分享卡片发给对方，**卡片标题＝生成的问候语**。B 站如果拒了卡片，会自动降级成纯文字再发一次 |
| **文本 + 链接** | 纯文字私信，正文后面附上那条视频的链接 |

面板底下还有一个 **带上视频标题** 开关（默认打开）和一个 **正文字数上限**（默认 40 字）：

**带上视频标题**
- 勾着：文字私信末尾多一行 `《视频标题》`，对方一眼知道你在说哪条视频；卡片形态下卡片标题会换成问候语正文。
- 取消：文字私信不附标题；卡片形态保持原来的视频标题。

**正文字数上限**（v1.5.1）
- 默认 **40 字**，可调 10–400。只算正文——`@` 昵称和署名 `——笨蛋鲸鱼娘` **不计入**。
- 超了自动截到最后一个分句（截断点落在后 40% 之内就切在 `，。！；` 上），不会剩半句话。
- 日志会打 `正文字数 39/40`；发生截断时会 warn 出截前截后各多少字。

两种都是照 B 站 web 私信接口实现的。注意：**卡片形态有一层平台限制**——官方文档写明 web 端点只支持
`msg_type` 1/2/5，卡片是 7，所以程序的做法是「先按卡片发，被拒就降级成文字」，日志里会写清是哪种情况。

> 对方如果关了私信权限、或者你们不是互关，可能报 `25003`（隐私设置）或 `21047`（对方回复/关注前最多 1 条），
> 这是平台的规矩，程序绕不过去。

### 6. 自动任务
- **周期计时**：每 N 分钟跑一次。
- **闹钟模式**：指定日期 + 时刻，可勾"每天重复"，不勾就只跑一次（跑完自动停用）。
- 每个自动任务可以单独设条数、是否干跑、**是否发私信**；下次执行时间会显示在卡片上，列表里还有「私信 / 评论」标签。
- 一次性任务的时间过了之后会自动停用，不会留下一个永远不执行的"僵尸任务"。

### 7. DeepSeek 设置
见下面第三节。

### 🎨 皮肤
- 4 套预设：**深海默认 / 幽蓝深洋 / 樱吹雪 / 纯黑省电**，点缩略图即切换。
- 点「⬆ 导入并启用」上传自己的 **PNG / JPG / WebP** 当背景（上限 8 MB），导入即生效。
- 自定义皮肤文件存在 `data/skins/`，**不塞进 config.json**（避免配置文件膨胀）。
- 切换结果立即持久化，下次启动自动套用。

### 8 / 9 日志与历史
实时日志（自动滚动、带可点链接）、任务历史（计划/成功/失败/跳过/用时）。

> 日志同时写一份到 `data/exe.log`（超过 2 MB 自动滚成 `exe.log.1`）。
> 网页里的日志台是内存态，重启就清空；要翻旧账就看这个文件。

#### 右上角日志小窗

页面往上翻、底下那块「运行日志」滚出视野时，右上角会自动浮出一个小窗接着显示日志；
滚回去看到完整日志，小窗自动收起。

- **可拖动**：按住小窗标题栏拖到任意位置（限制在窗口内，拖不出界），**松手不会误收成一条**。
- **可改大小**：右下角的 `⋰⋰⋰` 手柄拉着改尺寸（260×120 ～ 720×560）。
- 位置和大小自动记在浏览器 localStorage，**下次打开还是这个位置**。
- 标题栏点一下收成一条；`✕` 收成「● 实时日志」小气泡；「跳到完整日志 ↓」直接滚到底部那块。

### 📜 更新日志（顶栏按钮）
导航栏右上角 `更新日志` 按钮，点开直接看 `CHANGELOG.md` 的渲染结果（标题栏显示当前版本）。
`✕` / `Esc` / 点弹窗外空白处都能关。打包成 exe 后 CHANGELOG 已内嵌，不用在旁边放文件。

### 🪟 小窗布局与「▦ 窗口」菜单
九个分区都是独立小窗：按住标题栏拖动、点 `—` 收成一条、点 `✕` 关掉、拖右下角改大小。
位置尺寸存在浏览器 localStorage，下次打开还是这个布局。

顶栏 `▦ 窗口` 下拉里能逐个勾选开关（勾完菜单不关，方便连着开关好几个），底部还有
`全部显示` / `全部收起` / `重置布局`。要是把窗口全关掉了，右上角会浮出「⤢ 唤出控制台」气泡，一点全回来。

### ▣ 终端
顶栏 `终端` 按钮打开。它有两个用处：

- **看服务端输出**：打包成 exe 是 GUI 子系统，没有黑窗口，服务端 `console.log` 以前会静默消失；
  现在这些输出会实时流到这个终端里（启动信息、任务日志、报错都能看见）。
- **敲门命令**：在项目目录里执行任意命令（`echo`、`node --version`、`node build.mjs`…）。
  回车执行、`↑`/`↓` 翻历史、`cls` 清屏；`cd` 是单独处理的（裸 `cd` 回项目根、`cd public` 换目录，
  关掉终端再打开还记得当前目录）。跑飞了点 `■` 会 `taskkill /t` 把整棵进程树收掉。

终端窗口一样能拖、能改大小、位置记在 localStorage。

### 🎨 主题色

皮肤区底部有 7 个预设配色块，点一下整站换色（边框、按钮、高亮、焦点光圈一起变），选过的会记住。

**逐项配色**：点「🎛 逐项配色」展开编辑器，8 组 50 项颜色全都能单独调——
页面底色与光斑、九个分区的底色和边框、正文/次要文字、主色副色、
运行日志里每一级（步骤/信息/时间戳/成功/警告/错误/指示灯）、终端（普通输出/错误/系统消息/我敲的命令/提示符）、
更新日志弹窗的每一块、以及成功/警告/错误/危险按钮这些提示色。

| 分组 | 内容 |
| --- | --- |
| 背景 | 底色、底部渐深、左上光斑、右上光斑 |

| 线条与文字 | 边框线、正文、次要文字、主色块上的字 |
| 主色 | 主色、副色 |
| 运行日志 | 日志面板底、步骤行、信息行、时间戳、成功行、警告行、错误行、活跃指示灯 |
| 终端 | 终端底色、普通输出、错误输出、系统消息、我敲的命令、时间戳、提示符 |
| 更新日志弹窗 | 弹窗底色、标题栏、正文、标题字、代码底色/字色/边框、分隔线、版本标签 |
| 按钮 / 提示 | 成功、警告、错误、粉色点缀、危险按钮、干跑标记、成功提示 |

- 调了任意一项就自动切成「自定义」，色块列表里会多出一个，点它能一键切回别的方案。
- 「💾 存成自定义配色」把它固定住；「↺ 恢复预设」回到当前预设的原始颜色；「⧉ 复制 CSS」导出 `:root{…}`。
- 配色除了存浏览器本地，也写进 `config.json` 的 `ui.theme`，换端口/换浏览器/清缓存都不会丢。
  服务端会校验：预设下标必须是 0–999 的整数，自定义配色只收合法键名和字符串值，整体不超过 8KB。
- 顶栏底色、焦点光圈、hairline 这些半透明色由主色和底色**现算**，改主色它们跟着变。

**取色面板**：点任意一项左边的色块，原地弹出取色面板，不用去开系统取色器。

| 区块 | 怎么用 |
| --- | --- |
| 常用色 | 30 个（黑 → 灰阶 → 基础色），一点即用 |
| 同色调 | 按当前色相铺 10 档亮度，调深浅不用自己算 |
| 色相 | 12 色相 × 3 档明暗 = 36 格，换色系直接挑 |
| 色码输入 | 认 `#abc` / `#aabbcc` / 不带 `#`，边敲边实时上色；认不出只标红，不改坏已有颜色 |

底下还有「− 变暗 / + 变亮」（每档 8）和「↺ 该项默认」。面板贴着色块弹，右边不够就翻到左边；
点外面或按 Esc 关掉，窗口缩放会跟着重新定位。

## 三、AI 接口（任何 OpenAI 兼容供应商都能接）

### 走的是什么协议

标准的那一套，没有私有约定：

```
POST  {Base URL}/chat/completions
Authorization: Bearer <你的 key>
Content-Type: application/json

{"model": "...", "messages": [...], "temperature": 0.9}
```

所以只要供应商自称 **OpenAI 兼容**，填对 Base URL 就能用。

### 怎么配

在第 7 区「AI 接口（OpenAI 兼容）」：

1. **点供应商预设** —— 自动填好 Base URL 和模型。内置：Fiime / opc.fiime.cn（本机默认）、DeepSeek 官方、OpenAI、Kimi、智谱 GLM、阿里通义、硅基流动、OpenRouter、本地 Ollama、本地 LM Studio、自建 one-api/new-api。
2. **粘 API Key** —— 不落盘，只存内存。
3. **点「测试连通」** —— 会回显**最终请求的 URL、模型、鉴权方式**，失败时给出可读原因和供应商原文。

### 字段说明

| 字段 | 说明 |
|---|---|
| **Base URL** | 只填到版本号那层，例如 `https://opc.fiime.cn/api/model-service/v1`，程序自动补 `/chat/completions`。**粘完整端点也没关系**，重复后缀会被自动剥掉；没写 `https://` 会自动补。 |
| **模型** | 供应商文档里的模型 id，例如 `deepseek-v4-flash`。 |
| **鉴权方式** | `bearer`（默认）/ `api-key`（Azure）/ `x-api-key` / `none`（本地服务免鉴权）。 |
| **自动读取的凭据名** | 填 `OPCFIIME_API_KEY` 这种名字，程序每次启动会去 `~/.dsh/.credentials.yaml` 的 refs 段（或同名环境变量）里读 Key。**填了它就不用每次重启都重新粘 Key。** 找不到时会提示凭据文件里到底有哪些可用名字。 |
| **完整端点** | 可选。填了就**完全覆盖**地址拼装，支持带查询串 —— 接 Azure 这类必须用。 |
| **额外请求头** | 可选。每行一个 `Name: value`，用于 OpenRouter 的 `HTTP-Referer` / `X-Title` 之类。 |

### Key 从哪来（优先级）

1. **控制台手动粘的 Key** —— 只进内存，当次运行有效。
2. **凭据名对应的环境变量** —— 名字由「自动读取的凭据名」决定。
3. **`~/.dsh/.credentials.yaml` refs 段里同名条目**。
4. 兜底：按 Base URL 猜（`opc.fiime.cn` → `OPCFIIME_API_KEY`、`moonshot` → `MOONSHOT_API_KEY`…）。

- Key **只存在内存里**，不写进 `data/config.json`，界面和配置里只会出现 `opc_sk_***9ef4` 这种掩码。
- 早期版本曾把 key 明文写进配置文件，现在启动时会自动读进内存并从文件里删掉。
- 第 7 区会显示当前 key 的**掩码和来源**，便于确认用的到底是哪一个。
- Key 失效（`401`）直接在输入框粘新的、点保存即可，只对本次运行生效。

### 兼容性处理（踩过坑之后加的）

- **不支持 `response_format` 的供应商**：分析偏好时会带 `response_format: {type:'json_object'}`，很多第三方不支持这个参数会直接 400。程序检测到这类错误会**自动去掉该参数重试一次**。
- **限流 / 过载**：`429 / 500 / 502 / 503 / 504` 会**自动退避重试**（2s、4s，最多 3 次），不会因为一次临时过载废掉整轮任务。
- **模型不听话包了 ```json 围栏**：会先剥围栏再取 JSON，不会因为围栏解析失败。
- **多模态供应商返回数组 content**：会把文本片段拼回。

### 本机默认供应商（Fiime）

你的 DSH profile 里已经配了一个 OpenAI 兼容供应商，控制台预设里直接选就行：

| 项 | 值 |
|---|---|
| Base URL | `https://opc.fiime.cn/api/model-service/v1` |
| 模型 | `deepseek-v4-flash` 或 `deepseek-v4-pro` |
| 鉴权 | Bearer（key 形如 `opc_sk_...`） |

实测（2026-10-16）：`GET /models` 带 Bearer 返回 **22 个模型**，两个 v4 模型都在列且启用；
但当时 `/chat/completions` 返回 **503 模型服务当前并发繁忙**——这是供应商侧过载，等一会儿或换个模型再试。

## 五、安全与风控（请认真看）

**关于 cookie**
`SESSDATA` 等同于账号登录凭证，谁拿到谁是号主。它明文存在 `data/config.json` 里，这是本机文件。
如果哪天不想用了，去 B 站网页端**退出登录**，旧 SESSDATA 立刻失效。

**给自己clone的人的一句话**
仓库里**没有任何真实 cookie / API key**——脚本和测试里出现的都是 `FAKE_...` / `xxx` 之类的假值。
你自己的 cookie 只会待在本机 `data/config.json`，而那个目录在 `.gitignore` 里，不会被提交。
如果你要把自己的改动推回上游，**先跑一遍下面这段再 push**：

```bash
git secrets --scan          # 或自己 grep 一遍 SESSDATA / bili_jct / opc_sk_
git status --porcelain      # 确认 data/ dist/ 没被 track
```

**关于风控**
B 站禁止自动化操作。程序内置了三道缓冲：每条之间强制间隔、每日上限、默认干跑。但**风险不可能归零**——被要求验证码（`12015`）或被限流都是可能的。建议：

- 先干跑确认文案，再小批量真发
- 单个号每天别超过 10 条
- 别用同一个号在多条视频下发一模一样的评论（`12051` 会拦）

**关于接口**
`@` 是正文文本约定，没有独立参数。B 站接口支持正文里多个 `@`，实测两个 @ 都能解析成真实提及（接口返回里带对方 mid）。
接口地址：`POST https://api.bilibili.com/x/v2/reply/add`，参数 `type=1 / oid=aid / message / plat=1 / csrf=bili_jct`。

## 六、已知限制

1. **发送行为不可撤销**——评论发出去只能手动去 B 站删（干跑模式下不会发）。
2. 搜索接口返回的标题带 `<em>` 高亮，程序已做 HTML 实体解码，但如果 B 站改字段可能失效。
3. 定时任务靠进程内的 20 秒轮询实现，**控制台进程关掉就不跑了**；电脑休眠期间错过的周期任务不会补跑（只跑当下这一次）。
4. 配置文件加载失败时会**备份原文件、从默认值运行、且不写回覆盖**（踩过坑之后加的保险，备份名形如 `config.json.broken-<时间戳>`）。
5. exe 的注入会破坏 Authenticode 签名，Windows SmartScreen 首次运行可能提示"未知发布者"，选"仍要运行"即可。
6. exe 数据目录在自身同级目录，**不要放在需要管理员权限的路径**（如 `C:\Program Files\`），否则写不了配置。
7. 换新版本的 exe 时，**记得把旧的 `data\` 目录一起带过去**，账户和名单都在里面。
8. 双击运行时没有控制台窗口，**排错请看 `data\exe.log`**；如果是启动阶段就失败，浏览器会自动打开一张错误页告诉你原因。
9. 自动开浏览器依赖系统关联的默认浏览器；如果它打不开，日志里会有一条警告，手动访问 `http://127.0.0.1:8787` 即可。
